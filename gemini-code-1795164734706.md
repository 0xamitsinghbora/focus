# Focus App — Audio Guidance & Trataka Reset Spec

## 1. Cognitive Rationale & Design Constraints

- **Lyrical music hurts deep work:** Lyrics compete for verbal working memory during reading, writing, coding, and studying. Instrumental music is mostly neutral; upbeat music helps repetitive or low-cognitive tasks.
- **Broadband noise > binaural beats:** White, pink, and brown noise work via auditory masking (blocking sudden environmental spikes) and steady baseline arousal. Binaural beats have weak/mixed clinical backing and should not be marketed with brainwave claims.
- **Trataka ("Dot Method") resets task friction:** Short zero-input stillness lowers stimulation so starting demanding work feels easier than doing nothing.
- **Privacy-first rule (no spying):** Do not inspect OS media players, Spotify APIs, or browser tabs to police audio. Rely strictly on user goal context and optional self-logged check-ins.

## 2. Context-Aware Audio Guidance

Integrate music guidance into Focus's four existing surfaces instead of adding a music player or hard bans:

| Existing Surface             | Feature Addition                                                                                                          | Purpose                                                                                                  |
| :--------------------------- | :------------------------------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------- |
| **Daily Goal Planning**      | Add a 2-way goal toggle: **Deep Focus** (reading, coding, writing) vs. **Light / Routine** (admin, emails, chores).       | Sets audio context once in the morning with zero extra prompts.                                          |
| **Calming Focus Sounds**     | Add **Brown Noise** alongside white noise/rain + a **"Fade to Silence (5m)"** toggle.                                     | Helps music-dependent users start with steady sound, then smoothly transition into silence once in flow. |
| **Friendly Check-in Popups** | Add an optional 1-click pill row (`Silence` / `Focus Sound` / `Music`).                                                   | Surface a gentle nudge _only_ when the user logs low focus while listening to music.                     |
| **End-of-Day Review**        | Show a local comparison stat after 5+ check-ins (e.g., _"Deep Focus completed: 82% in Silence/Rain vs. 48% with Music"_). | Let personal data—not app lectures—drive behavior change.                                                |

### Suggested Micro-Copy

- **Deep Focus goal start (dismissible):** _"Tip: Lyrics compete with reading and problem-solving. Silence or Rain usually works better here."_
- **Routine goal start:** _"Routine work—put on whatever music keeps your pace up."_
- **Distracted check-in + Music:** _"Feeling scattered? Try pausing lyrics and switching to Rain or Silence for the next 20 minutes."_

## 3. Trataka "Dot Reset" (90-Second Mind Reset)

Reframe the 15–20 minute wall-stare into a practical **60–120s Decompression Overlay** to avoid drop-off and monitor eye strain.

### Entry Points

1. **Check-in Popup:** Place a **`90s Dot Reset`** button next to `Snooze` to help users break out of distraction rabbit holes.
2. **Floating Timer:** Add a subtle dot icon (`◉`) in hover controls for manual resets between tasks.
3. **Morning Launch:** Optional toggle on the first Deep Focus goal (_"Start with 60s Mind Reset"_).

### Desktop UX & Eye-Safety Spec

- **Window:** Frameless fullscreen `BrowserWindow` (`alwaysOnTop: true`), warm charcoal background (`#0E0E0E`), and instant **`Esc` to exit**.
- **Visual Target:** Single soft off-white/warm amber dot (`8px–12px`, subtle `2px` blur) dead center. Hide numeric countdowns so users aren't clock-watching.
- **Eye-Strain Guardrail:** Fade in a 4-second cue at start, then fade out completely:
  > _"Rest your eyes softly on the dot. Blink naturally. Let the noise settle."_
- **Audio Handoff:** Fade out any active Focus Sound to true silence during the reset, play one soft low-frequency chime on completion, and return straight to the active timer.
- **Presets:** Default **90s**, with optional pre-start chips for **60s / 2m / 5m**.

---

## 4. Technical Implementation Notes

- **Procedural Audio Engine:** Generate White, Pink, and Brown noise in real time using the **Web Audio API** (`AudioWorklet`) to keep cross-platform installers (`.exe`, `.dmg`, `.AppImage`, `.deb`) small, 100% offline, and seamlessly looped.
- **Backward-Compatible Schema Addition:** Append optional fields to existing local check-in records (preserving Google Drive backup compatibility):

```json
{
  "goalType": "deep | routine",
  "audioMode": "silence | focus_sound | music | null",
  "didDotReset": true
}
```
